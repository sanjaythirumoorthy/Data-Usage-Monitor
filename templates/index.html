About This Project

Academic Data Science Capstone Documentation

Project Objective

The Daily Data Usage Monitoring & Analytics system is developed as a collegiate Data Science application designed to track and monitor daily internet/mobile data consumption. It uses Python, Pandas, and NumPy for automated data preprocessing, statistical metrics computation, behavioral trend discovery, and real-time threshold alert detection.

Academic Data Science Concepts Demonstrated
Data Preprocessing Handling missing values, deduplication, date coercing with Pandas.
Statistical Analysis Mean, median, standard deviation, max/min with NumPy.
Exploratory Data Analysis Distribution visualization via Matplotlib and Chart.js.
Threshold Anomaly Monitoring Boolean vectorization for excess bandwidth violation detection.
Technology Stack
Python 3 Flask Pandas NumPy Matplotlib Chart.js Bootstrap 5 JavaScript (ES6+)
Status Threshold Classification
Category Bandwidth Condition Interpretation
Low Usage < 2.0 GB Minimal activity (browsing/text)
Normal 2.0 GB ≤ Usage ≤ 4.0 GB Standard everyday streaming & work
High Usage > 4.0 GB Heavy video streaming/gaming/downloads
